# AURELLE

### A Little Light, Every Day.

**AURELLE** is an elegant beauty and skincare website concept designed to deliver a refined digital shopping experience. It combines editorial-inspired design, interactive product displays, smooth animations and responsive layouts to create an engaging brand experience.

🔗 **[View Live Website](https://christianaoladosu.github.io/Aurelle/)**

---

## Overview

AURELLE explores how thoughtful design and frontend development can work together to create a distinctive digital brand experience.

The project focuses on visual storytelling, intuitive navigation, responsive design and interactive functionality.

Rather than presenting products in a conventional catalogue, AURELLE uses carefully structured sections, visual elements and subtle motion to communicate its brand identity.

## Technologies

* **HTML5:** Semantic structure and content organisation.
* **CSS3:** Custom styling, responsive layouts, transitions and animations.
* **JavaScript:** Interactive components and dynamic user interactions.
* **Git & GitHub:** Version control and project hosting.
* **GitHub Pages:** Public website deployment.

## Features

* Animated introductory experience.
* Responsive navigation and mobile layout.
* Editorial-style hero section.
* Custom CSS product illustrations.
* Interactive product collection.
* Ingredient information sections.
* Skincare routine presentation.
* Interactive shopping bag demonstration.
* Checkout form validation.
* Expandable FAQ sections.
* Smooth visual transitions and animations.

## Design Direction

AURELLE uses a warm, understated visual identity built around:

* Soft cream and blush tones.
* Elegant typography.
* Minimalist product presentation.
* Spacious layouts.
* Subtle animations and transitions.

The intention is to create a digital experience that feels calm, polished and memorable.

## Important Note

AURELLE is a portfolio website concept. Product descriptions, formulations and prices are illustrative.

The shopping bag and checkout interactions are demonstrations. The website does not process real orders or payments.
