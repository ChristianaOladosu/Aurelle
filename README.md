# AURELLE

### A Beauty and Skincare Brand Website

Aurelle is a website concept developed for a beauty and skincare brand. The project focuses on creating an elegant digital experience that presents products, communicates brand identity and makes browsing intuitive.

## Project Overview

The goal of this project was to build a visually appealing website that combines thoughtful styling, structured content and interactive elements.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

* Responsive website layout
* Custom visual styling
* Interactive elements
* Product-focused presentation
* Brand-oriented design
